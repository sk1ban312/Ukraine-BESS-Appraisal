# Ukraine Grid-Scale Battery Storage: A World Bank–Style Shadow Appraisal

Independent appraisal of a grid-scale battery (BESS) in Ukraine, built from
public market data — from the investor's view (financial) and the country's
view (economic).

## Question
Is a grid-scale battery (BESS) in Ukraine worth building, and does adding
gas-engine cogeneration (CHP) create value beyond what each delivers alone —
for an investor and for Ukraine?

## Approach
| Phase | Scope | Status |
|---|---|---|
| 1 | BESS alone | 🔄 Defining screening criteria |
| 2 | CHP alone | ⏳ Not started |
| 3 | Hybrid BESS + CHP — synergy test | ⏳ Not started |
| 4 | Financing & economic value to Ukraine | ⏳ Not started |

Each phase is analysed two ways:
- **Financial** — would a private investor build it?
- **Economic** — is it worth it for Ukraine?

Go/no-go criteria are fixed **before** any analysis →
[Screening criteria](docs/screening-criteria.md)

## Data
Hourly day-ahead (DAM) and intraday (IDM) prices, Jan 2025 – Oct 2026.
Source: Market Operator of Ukraine ([oree.com.ua](https://www.oree.com.ua)).
